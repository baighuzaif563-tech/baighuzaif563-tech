## 🔧 &nbsp;How to Show ALL Commits (One-Time Setup)

> **The public stats API cannot read private repos. Deploy your own free instance in ~5 minutes:**

```
Step 1 → Go to https://github.com/anuraghazra/github-readme-stats
Step 2 → Click "Fork" (top right)
Step 3 → Go to https://vercel.com → Sign in with GitHub → "Add New Project"
Step 4 → Import your forked repo
Step 5 → Add Environment Variable:
          Key:   PAT_1
          Value: (your GitHub Personal Access Token)
          → Create token at: github.com/settings/tokens
          → Select scopes: repo (full), read:user
Step 6 → Click Deploy → Copy your Vercel URL
Step 7 → Replace YOUR_VERCEL_URL in this README with your Vercel URL
```

✅ Done! Your stats card now auto-updates with **all commits, all repos, forever.**
